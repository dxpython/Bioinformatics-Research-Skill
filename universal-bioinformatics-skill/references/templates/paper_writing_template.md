# Manuscript writing template

> Guidance and boilerplate for bioinformatics papers: Methods, Results, figure legends, Discussion, Limitations, and Conclusion. Journal-ready paragraphs are in English.

---

## 1. Methods

### Principles

1. **Reproducibility:** Another analyst can repeat the analysis from your text alone.
2. **Completeness:** Software name + version + key parameters + statistics.
3. **Logical order:** Follow the actual analysis pipeline.
4. **Citations:** Cite primary references for tools and databases on first use.

### Template 1: Data acquisition and preprocessing

> **Data acquisition and preprocessing**
>
> The RNA-seq gene expression data (level 3, HTSeq-Counts/HTSeq-FPKM) and corresponding clinical information of [cancer type] patients were downloaded from The Cancer Genome Atlas (TCGA, https://portal.gdc.cancer.gov/) using the R package TCGAbiolinks (v[version]) [ref]. A total of [N] tumor samples and [N] normal samples were included. Samples with incomplete survival data or follow-up time less than 30 days were excluded. For validation, gene expression profiles and clinical data of [dataset ID] (GPL[platform]) were obtained from the Gene Expression Omnibus (GEO, https://www.ncbi.nlm.nih.gov/geo/) using the GEOquery package (v[version]) [ref]. The raw microarray data were normalized using the Robust Multi-array Average (RMA) algorithm. For datasets from different platforms, gene expression values were log2-transformed and quantile-normalized. Batch effects between datasets were assessed by principal component analysis (PCA) and corrected using the ComBat algorithm implemented in the sva package (v[version]) [ref].

### Template 2: Differential expression

> **Differential expression analysis**
>
> Differential expression analysis between [group A] (n = [N]) and [group B] (n = [N]) was performed using the DESeq2 package (v[version]) [ref] in R (v[version]). Raw count data were used as input, and the default independent filtering procedure was applied to remove low-count genes. Genes with |log2 fold change| > [threshold, e.g., 1] and Benjamini-Hochberg (BH) adjusted p-value < [threshold, e.g., 0.05] were defined as differentially expressed genes (DEGs). Results were visualized using volcano plots generated by the EnhancedVolcano package (v[version]) and heatmaps generated by the ComplexHeatmap package (v[version]) [ref].

### Template 3: Functional enrichment

> **Functional enrichment analysis**
>
> Gene Ontology (GO) and Kyoto Encyclopedia of Genes and Genomes (KEGG) pathway enrichment analyses were performed using the clusterProfiler package (v[version]) [ref] in R. DEGs were mapped to Entrez Gene IDs using the org.Hs.eg.db annotation package (v[version]). Enrichment significance was determined using a hypergeometric test with BH correction. Terms with adjusted p-value < [threshold, e.g., 0.05] were considered significantly enriched. Gene Set Enrichment Analysis (GSEA) was performed using the fgsea package (v[version]) [ref] with the hallmark gene sets (h.all.v[version].symbols.gmt) from the Molecular Signatures Database (MSigDB, v[version]) [ref]. Genes were pre-ranked by the log2 fold change from differential expression analysis. Gene sets with |NES| > [threshold] and FDR q-value < [threshold] were considered significantly enriched.

### Template 4: Prognostic model

> **Construction and validation of the prognostic model**
>
> Univariate Cox proportional hazards regression was first performed to screen genes significantly associated with overall survival (OS) (p < [threshold, e.g., 0.05]). The least absolute shrinkage and selection operator (LASSO) Cox regression was then applied using the glmnet package (v[version]) [ref] with 10-fold cross-validation to select the optimal lambda value and prevent overfitting. The risk score was calculated as follows: Risk Score = [formula_placeholder]. Patients were dichotomized into high-risk and low-risk groups based on the median risk score. The Kaplan-Meier method was used to estimate survival curves, and the log-rank test was used to compare survival between groups. Time-dependent receiver operating characteristic (ROC) curves were generated using the timeROC package (v[version]) [ref] to evaluate the predictive accuracy at 1, 3, and 5 years. The model was validated in an independent cohort ([dataset name], n = [N]). The proportional hazards assumption was tested using Schoenfeld residuals.

### Template 5: Immune infiltration

> **Immune cell infiltration analysis**
>
> The abundance of tumor-infiltrating immune cells was estimated using multiple algorithms, including CIBERSORT [ref], ssGSEA (implemented in the GSVA package, v[version]) [ref], and the ESTIMATE algorithm [ref]. For CIBERSORT analysis, the LM22 signature matrix was used with 1000 permutations, and samples with CIBERSORT p < 0.05 were retained for downstream analysis. The tumor purity, ESTIMATE score, immune score, and stromal score were calculated using the estimate package (v[version]). The correlation between the risk score and immune cell abundance was assessed using Spearman's rank correlation coefficient. Differences in immune cell infiltration between high-risk and low-risk groups were compared using the Wilcoxon rank-sum test with BH correction for multiple comparisons.

### Template 6: Single-cell RNA-seq

> **Single-cell RNA sequencing analysis**
>
> Single-cell RNA-seq data were processed using the Seurat package (v[version]) [ref] in R. Cells with fewer than [N] genes, more than [N] genes, or more than [N]% mitochondrial gene expression were filtered out. Data were normalized using the SCTransform method [ref], and the top [N, e.g., 3000] highly variable genes were selected. Dimensionality reduction was performed using PCA, and the top [N, e.g., 30] principal components were selected based on the elbow plot. Cells were clustered using the shared nearest neighbor (SNN) algorithm with a resolution of [value], and visualized using Uniform Manifold Approximation and Projection (UMAP). Cell type annotation was performed based on canonical marker genes and confirmed using the SingleR package (v[version]) [ref] with the [reference dataset] as reference. Differentially expressed genes between clusters were identified using the Wilcoxon rank-sum test (FindMarkers function, min.pct = [value], logfc.threshold = [value]).

### Template 7: Statistical analysis (overview)

> **Statistical analysis**
>
> All statistical analyses were performed using R software (v[version], R Foundation for Statistical Computing, Vienna, Austria). Continuous variables were compared using [Student's t-test / Wilcoxon rank-sum test] for two groups and [one-way ANOVA / Kruskal-Wallis test] for multiple groups, as appropriate. Categorical variables were compared using the chi-squared test or Fisher's exact test. Correlation analyses were performed using [Pearson / Spearman] correlation coefficient. Multiple testing correction was performed using the Benjamini-Hochberg method. All statistical tests were two-sided, and p < 0.05 was considered statistically significant unless otherwise stated.

## 2. Results

### Principles

1. **Figure-driven:** Each subsection maps to a figure or table; describe the panel then state the conclusion.
2. **Factual tone:** Report findings; defer mechanism to Discussion.
3. **Numbers:** Report p-values, HR, AUC, counts, etc.
4. **Cross-references:** Cite figure/table IDs after each key claim.

### Overall Results outline

```
3.1 [Descriptive title: cohort overview or DEG screen]
    → Figure 1 / Table 1
    → Data source, sample size, baseline characteristics

3.2 [Core finding 1]
    → Figure 2
    → Main differential results

3.3 [Core finding 2]
    → Figure 3
    → Functional analysis

3.4 [Core finding 3]
    → Figure 4
    → Modeling and validation

3.5 [Extended analyses]
    → Figures 5–6
    → Immune / drug / mechanism angles

3.6 [Experimental validation if any]
    → Figure 7
    → qPCR / WB / IHC
```

### Paragraph flow

Each Results paragraph: **motivation → method (brief) → numeric outcome → one-line takeaway.**

```
Example:
  [Motivation] To investigate the role of [X] in [disease], we...
  [Method] performed [analysis] using [tool].
  [Outcome] A total of [N] [genes/features] were identified, including...
         Top pathways included [pathway 1] and [pathway 2] (Fig. X).
  [Takeaway] These results suggest [brief conclusion].
```

## 3. Figure legends

### Principles

1. **Self-contained:** A reader understands the figure from the legend alone.
2. **Consistent format:** Overall title, then panels (A), (B), …
3. **Complete:** colors, statistics, n, thresholds.

### Legend skeleton

```
Figure [N]. [One-line summary of the whole figure]

(A) [Panel description]. [Plot type] showing [content]. [Color/symbol key].
    [Statistical test]. n = […].

(B) [Panel description]. Rows/columns represent […]. [Normalization].
    [Clustering method].

(C) [Panel description]. Comparison of [metric] between [groups].
    [Statistical test]. * p < 0.05, ** p < 0.01, *** p < 0.001; ns, not significant.

Abbreviations: [abbr], [full form]; …
```

### Example legend 1 (DE figure)

> **Figure 2. Identification of differentially expressed genes between HCC tumor and adjacent normal tissues.**
>
> (A) Volcano plot showing the differentially expressed genes (DEGs). The x-axis represents log2(fold change) and the y-axis represents -log10(adjusted p-value). Red dots indicate significantly upregulated genes (log2FC > 1, adjusted p < 0.05), blue dots indicate significantly downregulated genes (log2FC < -1, adjusted p < 0.05), and gray dots indicate non-significant genes. Key genes are labeled. (B) Heatmap of the top 50 DEGs (25 upregulated and 25 downregulated). Expression values were Z-score normalized across samples. Rows represent genes and columns represent samples. The color bar on top indicates sample groups (red, tumor; blue, normal). Hierarchical clustering was performed using Euclidean distance and Ward's linkage method. (C) Venn diagram showing the overlap of DEGs identified in the TCGA-LIHC (blue) and GSE[XXXXX] (yellow) datasets. The number of shared DEGs is indicated in the intersection area.

### Example legend 2 (survival figure)

> **Figure 4. Prognostic value of the cuproptosis-related risk score in HCC.**
>
> (A) Kaplan-Meier survival curves for overall survival (OS) in the high-risk (red, n = [N]) and low-risk (blue, n = [N]) groups in the TCGA training cohort. The p-value was calculated by the log-rank test. The table below shows the number of patients at risk at each time point. (B) Kaplan-Meier survival curves for OS in the GEO validation cohort (GSE[XXXXX]). (C) Time-dependent ROC curves for 1-year (red), 3-year (blue), and 5-year (green) OS prediction. AUC values are shown in the legend. (D) Nomogram integrating the risk score and clinicopathological variables for predicting 1-, 3-, and 5-year OS. (E) Calibration curves for the nomogram. The dashed diagonal line represents the ideal prediction, and the colored lines represent the observed prediction at 1-year (red), 3-year (blue), and 5-year (green).
>
> Abbreviations: OS, overall survival; AUC, area under the curve; HR, hazard ratio; CI, confidence interval.

## 4. Discussion

### Recommended structure

```
Paragraph 1 — Opening
  → 1–2 sentences on main findings and novelty

Paragraphs 2–4 — Key findings
  → One paragraph per major result: recap → literature → cautious mechanism

Paragraph 5 — Clinical implications
  → Translation, biomarker use, treatment stratification (hypothesis-level)

Paragraph 6 — Limitations
  → Honest limits + mitigation or future work

Paragraph 7 — Closing
  → Restate contribution and outlook
```

### Opening paragraph

> In the present study, we systematically investigated [research topic] in [disease/context] using [data types / methods]. Our analysis identified [major finding 1], revealed [major finding 2], and demonstrated [major finding 3]. To the best of our knowledge, this is the first study to [novelty claim]. These findings provide new insights into [biological/clinical significance].

### Key finding paragraph

> [Recap] Our analysis revealed that [specific finding, e.g., Gene X was significantly upregulated in tumor tissues and associated with poor prognosis].
>
> [Literature] This finding is consistent with previous studies reporting [similar findings] [ref1, ref2]. However, [Author et al.] reported [different finding] in [context] [ref3], which may be attributed to [possible explanation].
>
> [Mechanism, cautious] Mechanistically, [Gene X / Pathway Y] has been reported to [known function] through [mechanism] [ref4]. Our enrichment analysis further suggested involvement in [pathways], consistent with [process] in [disease] [ref5]. Experimental validation remains needed.

### Clinical implications

> From a clinical perspective, our findings have several potential implications. First, the [risk model / biomarker] may serve as a [complementary / independent] tool for [prognosis / treatment selection / early diagnosis] in [disease]. The [AUC / C-index] of [value] in the validation cohort suggests [acceptable / good / excellent] discrimination. Second, associations between [finding] and [immune checkpoint / drug sensitivity] may inform [immunotherapy / targeted therapy], pending prospective validation.

### Closing paragraph

> In conclusion, our study provides a comprehensive [analysis type] of [topic] in [disease/context], revealing [summary of key findings]. The [model / signature] we developed may facilitate [clinical application], and the [molecule / pathway / cell state] we identified offers directions for future [mechanistic / translational] research. Future studies integrating [prospective data / experiments / multi-center cohorts] are warranted.

## 5. Limitations

### Principles

1. **Honest but not self-defeating:** Acknowledge limits while noting mitigations.
2. **Specific:** Avoid vague "several limitations exist."
3. **Forward-looking:** Pair each limitation with a next step.

### Common limitation phrases

| Topic | Template |
|-------|----------|
| Retrospective design | "This study is retrospective in nature, which may introduce selection bias. Prospective studies are needed to validate our findings." |
| Sample size | "The relatively limited sample size (n = [N]) may have reduced power to detect [subtle effects]. Larger cohorts are warranted." |
| Public data quality | "Clinical annotations in public repositories may be incomplete or inconsistent, potentially affecting survival analyses." |
| No wet lab | "Although we validated key genes at the [mRNA / protein] level where possible, functional roles were not fully tested experimentally." |
| Single omics | "Our study was based on [transcriptomic] data alone. Integration with [genomic / epigenomic / proteomic] layers would broaden interpretation." |
| Batch effects | "Despite correction with [ComBat / limma], residual technical variation between datasets cannot be excluded." |
| Generalizability | "Cohorts were predominantly [ancestry/region]; performance in other populations needs evaluation." |

### Example limitations paragraph

> Several limitations should be acknowledged. First, this was a retrospective study using public data, subject to collection and annotation biases. Second, although the prognostic model was validated in an independent GEO cohort, prospective multicenter validation is still required. Third, mechanistic inferences rely on computational analysis and literature; gene perturbation and animal models are needed. Fourth, bulk RNA-seq averages heterogeneous cells; single-cell profiling would refine cellular mechanisms. Finally, the ethnic composition of TCGA/GEO may limit generalizability.

## 6. Conclusion

### Principles

1. **Concise:** Typically 3–5 sentences.
2. **No new data:** Do not introduce results not in Results/Discussion.
3. **Highlight value:** State the unique contribution clearly.

### Conclusion template

> In summary, [this study / our analysis] [identified / revealed / established] [core finding 1]. [We further demonstrated / Our findings suggest] that [core finding 2], which [is associated with / may contribute to] [biological/clinical meaning]. The [model/biomarker] developed here [provides / may serve as] a [potential] tool for [application]. These findings improve understanding of [field] and may inform [therapeutic / diagnostic / prognostic] strategies for [disease].

## Appendix: Style notes

### Verb tense

| Section | Tense | Example |
|---------|-------|---------|
| Methods | Past | "We performed…" |
| Results | Past | "A total of 256 DEGs were identified…" |
| Discussion (prior work) | Present | "Previous studies suggest…" |
| Discussion (your results) | Past | "Our analysis revealed…" |
| Discussion (general biology) | Present | "Gene X plays a role in…" |
| Conclusion | Mixed | "We identified… These findings provide…" |

### Wording

| Avoid | Prefer |
|-------|--------|
| prove | demonstrate / suggest / indicate |
| very significant | strongly associated / large effect |
| we found for the first time | to our knowledge, this is the first study to… |
| obviously | notably / interestingly |
| cure | improve outcomes / enhance efficacy |
| we believe | our findings suggest / we speculate |

### Figure citation formats

```
Common styles:
  - (Fig. 1A)
  - (Figure 1A)
  - (Supplementary Fig. S1)
  - (Table 1)

Follow the target journal's instructions.
```
